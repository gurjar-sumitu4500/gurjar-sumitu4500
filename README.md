<h2>🚀 What I'm building</h2>
<p>
  <a href="https://swaadhigam.com"><b>Swaadhigam (स्वाधिगम)</b></a> is a UPSC self-learning platform for civil-services aspirants:
  structured study notes, previous-year questions with model answers, AI answer evaluation, and 1:1 mentorship.
  I designed and built it end to end, from React front end and Node.js on AWS Lambda to Postgres and Terraform.
</p>
<ul>
  <li>📚 <a href="https://swaadhigam.com/notes">UPSC study notes</a>: GS, CSAT, Essay and optional subjects</li>
  <li>📝 <a href="https://swaadhigam.com/pyq">UPSC previous-year questions with answers</a></li>
  <li>🇮🇳 <a href="https://swaadhigam.com/hi/notes">UPSC notes in Hindi</a></li>
  <li>🤝 <a href="https://swaadhigam.com/mentors">1:1 UPSC mentorship</a></li>
</ul>
